# 趨勢模型（方法 E）

程式：`src/twmedia/trend.py`（模型）、`scripts/fit_trends.py`（擬合）；事件表：`config/events.yaml`。

## 模型

每家媒體、每個政黨各擬合一條隨機漫步軌跡：

```
μ_t = μ_{t-1} + η_t,   η_t ~ N(0, τ² · jump_t)
y_t = μ_t + ε_t,       ε_t ~ N(0, v_t)
```

- `y_t`：該期（月或週）所有提及該黨文章的平均立場分數
- `v_t`：該期平均的不確定性，由文章之間的離散程度除以篇數，再加上陪審員之間的分歧。文章少、或陪審員意見不一致的時期，區間較寬
- `τ`：每期正常的移動幅度，以最大化邊際概似在格點上選出
- 以卡爾曼濾波加 RTS 平滑求每期的精確後驗平均與 95% 區間；沒有文章的時期由隨機漫步銜接

## 已知事件

`jump_t` 平常是 1。事件所在的那一期設為 25，也就是那一期允許的移動幅度是平常的 5 倍。這只放寬模型「允許」的變化，不指定方向，也不保證會有變化。

事件依 `config/events.yaml` 開頭寫明的規則，從 [money-sources.md](money-sources.md) §5.2 的所有權與控制權事件表選出，不另外手動加入：

- 國民黨與民進黨之間的政黨輪替（2012–2026 期間只有 2016-05-20），套用到所有媒體
- 分析範圍內媒體的控制者變更：完成收購、控制者出售持股或過世
- 董事長變更，只計入沒有單一控制股東的媒體（公視、中央社、民視、三立）

不計入：表中標為背景或脈絡的事件、失敗或被否決的收購、換照、判決與裁罰、經營權爭議、董事席次變動、媒體創立，以及不在分析範圍內的媒體（中天、中視、壹電視、鏡電視、中嘉）。

## 有無事件的比較

使用決策模型 v1 的月資料（2026-11-07 擬合，117,946 篇），24 條序列：

| 項目 | 結果 |
|---|---|
| τ | 有事件時相同或略小（例如公視民進黨 0.021 → 0.013）：原本被平均分攤的跳動，改由事件那一期吸收 |
| 事件那一期的區間寬度 | 大多變寬，例如三立國民黨 0.32 → 0.64 |
| 任一期平均值的最大差異 | 0.07（自由時報民進黨） |
| 各媒體整體排序（國民黨 − 民進黨的平均） | 不變（Spearman ρ = 1.00），整體平均差異最大 0.008 |
| 倍數改為 6.25 或 100 | 排序仍不變（ρ = 1.00） |
| 2026-08 起的週資料 | 期間內沒有事件，結果與不加事件完全相同 |

## 與資金關聯分析（方法 F）的關係

方法 F 會在所有權與資金變化前後做事件研究。如果用來檢驗的序列事先被告知「這裡可以跳」，可能讓人質疑找到的變化是模型做出來的。因此 `fit_trends.py --no-events` 的無事件版本一併保留，方法 F 讀取的是這個版本；網站與報告的趨勢圖則使用有事件的版本，並在圖上標出事件。

## 資料來源的分界

2026 年 10 月起的文章來自即時收集（各版面），之前來自每月歷史抽樣（政治版）。分界前後的變化有一部分來自抽樣與模型，不全是媒體本身的改變，見 [source-switch.md](source-switch.md)。

## 輸出

`data/derived/trends_<期別>[_model][_noevents].json`：每條序列附 `tau`、`events`（套用的事件）與每期的篇數、平均值與 95% 區間。
