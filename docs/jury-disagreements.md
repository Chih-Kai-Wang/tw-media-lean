# 陪審團意見不一致的文章

日期：2026-11-07　陪審員：`gemini-3.8-flash`（Google）、`gpt-oss-120b-maas`（OpenAI（開源））、`llama-4-maverick-17b-128e-instruct-maas`（Meta（開源））

範圍：陪審一致性測試（[jury-agreement.md](jury-agreement.md)）中三位正式陪審員都判斷過的 2393 篇新聞。某篇文章對某個政黨，只要三位陪審員都給了立場分數，而且分數相差至少 2 分（−2 到 +2 的量尺），或有人判正面、有人判負面，就列為意見不一致。

清單只含媒體、日期、網址、標題與各陪審員的分數，不含內文；隨資料集一起公開（`jury_disagreements.csv`）。

## 用途

- 以陪審員標籤擬合的趨勢中，同一篇文章有多位陪審員時，他們的分歧會放寬該期的不確定區間（[trend-model.md](trend-model.md)）
- 讀者可以自行檢視這些文章，判斷哪一位陪審員比較合理，或標註規則哪裡需要釐清
- 下一版標註規則若有修改，會先用這批文章檢驗分歧是否減少
