# 標註問題組（Codebook）v0.1

LLM 陪審團對每篇文章回答同一組固定問題（PLAN.md 第 5.3 節）。這份文件是問題與選項的唯一定義；提示詞由 `src/twmedia/annotate.py` 依此產生。修改問題要升版號，舊標註不與新標註混用。

## 對象

國民黨（KMT）、民進黨（DPP）、民眾黨（TPP）。三黨分開判斷，不合併成單一藍綠分數。

「提及某黨」包括：政黨名稱、該黨的黨職人員、該黨籍的民選公職與候選人、該黨立法院黨團、該黨執政的中央或地方政府（以「執政黨」身分被評論時）。

## 每篇文章的問題

| 欄位 | 問題 | 選項 |
|---|---|---|
| `political` | 這篇文章的主題是否與台灣政治有關？ | true / false |
| `genre` | 文章類型 | `news`（新聞報導）／`opinion`（評論、社論、專欄）／`press_release`（政黨或政府新聞稿）／`other` |
| `topic` | 主要議題（單選） | `election`、`cross_strait`、`foreign_defense`、`economy`、`energy_environment`、`justice_scandal`、`legislature`、`social_welfare`、`other` |

## 每個政黨的問題

| 欄位 | 問題 | 選項 |
|---|---|---|
| `mentioned` | 文章是否提及該黨（定義見上） | true / false |
| `stance` | 整篇文章呈現該黨的方式，偏向正面還是負面？ | -2 強烈負面、-1 負面、0 中立或正負平衡、1 正面、2 強烈正面；未提及則為 null |
| `salience` | 該黨在文章中的份量 | 0 未提及、1 順帶一提、2 次要角色、3 主角 |
| `quoted` | 文章是否直接引述該黨人士的說法 | true / false |

## 判斷原則

1. **判斷文章怎麼呈現該黨**。報導某黨醜聞，若只是平實陳述事實並給予回應空間，`stance` 為 -1；若用語帶情緒、只呈現單方說法，才是 -2。
2. **引述不等於立場**。文章引述 A 黨批評 B 黨，若記者有平衡呈現 B 黨回應，B 黨的 `stance` 偏向 0。
3. **只看文章本身**，不參考媒體名稱或你對該媒體的既有印象。標註時不提供媒體名稱。
4. 新聞稿（`press_release`）照樣判斷，這是驗證用的已知立場文本。
