# 決策模型 v0

日期：2026-11-03　程式：`scripts/train_decision_model.py`、`scripts/predict_decision_model.py`

以 LLM 陪審團的標註訓練的中文編碼器，每個標註問題一個分類頭，用來免費標註其餘所有抽樣文章（研究設計方法 C）。

- 基底：`ckiplab/bert-base-chinese`，最長 512 字，3 輪
- 訓練資料：13,920 篇有 `gemini-3.8-flash` 標註的新聞與政黨新聞稿（訓練 11,106、驗證 1,342、測試 1,472，依文章編號切分）。robots.txt 標示 `ai-train=no` 的來源（中央社、PTT）不放入
- 每個分類頭以驗證集做溫度校準

## 判讀

- 立場與老師模型的平均絕對差約 0.35 分（−2 到 +2 量尺），完全相同約 73–77%。作為對照，兩個 Gemini 模型彼此的平均絕對差是 0.24–0.28、完全相同約 76%（[jury-agreement.md](jury-agreement.md)）。決策模型和老師的差距，比兩個 LLM 彼此的差距略大，但同一個量級
- 校準良好：除了民眾黨立場（測試樣本只有 183 篇），各問題的校準誤差都在 0.04 以下，輸出的機率可以直接當不確定性使用
- 這裡的「準確率」是和老師模型比，不是和真實答案比；老師本身的可信度見 [bulk-annotation.md](bulk-annotation.md)

## 限制與下一步

- 民眾黨的訓練樣本少，立場判斷的校準較差；需要更多提及民眾黨的標註
- 只蒸餾單一老師模型；加入其他陪審員後，改用多個模型的機率分布當訓練目標
- 模型與模型卡將於 Hugging Face 公開
