# 各媒體舊文章網址結構與歷史抽樣可行性（2012–2026）

調查日期：2026-11-02。目的：為「每家每月約 300 篇政治新聞」的隨機抽樣找出可行做法，以媒體自家網站優先，其次 Wayback。

**探測方式**：User-Agent 為 `twmedia-research/0.1 (+https://github.com/Chih-Kai-Wang)`；每個主機先讀 robots.txt，以 `twmedia-research` 判斷；同一主機至少間隔 3.2 秒；不跟隨 robots 不允許的轉址。每家僅發出少量請求（含 robots.txt 與子網域）。Wayback CDX 查詢間隔 3–8 秒，約一半回 503／504（與 [history-coverage.md](history-coverage.md) 所記的不穩定一致）。抓回的頁面未納入 repo。

下文的「ID → 日期」都是實際抓頁面讀到的 `article:published_time`／JSON-LD `datePublished`。各年 1 月的 ID 是用這些點做線性內插的**估計值**，標「≈」。

## 各家要點

- **中央社**：類別路徑寫錯不影響結果，`/news/aipl/<id>` 對任何存在的文章都回 200，`og:url` 會給出真正的類別（例如 `amov`、`afe`）。所以可以把「日期＋流水號」當全站 ID 來抽，再從 `og:url` 留下 `aipl`。`aopl` 目前是「國際」，`acn` 是兩岸。**[history-coverage.md](history-coverage.md) 將 2012–2015 的 `aopl` 計為政治，該數字應讀為「政治＋國際」。** 2012 年的舊網址是 `www2.cna.com.tw/News/aIPL/…-1.aspx`，Wayback 有存，自家網站已經 404。robots.txt 有 `Content-signal: ai-train=no`：可以拿來研究，不能拿來訓練模型。
- **自由**：類別錯了會 301／302 到正確的類別或子網域（`talk.`、`sports.`、`health.` 等，各子網域的 robots 都允許）。所以請求 `/news/politics/paper/<id>` 時，如果**最後沒有被轉走**，就是政治。2012–2014 只有 paper（報紙版）可用；breakingnews 在 2015 年前的抽測都是 404。注意 paper 和即時新聞的比例會隨年份改變。
- **聯合**：自家網站文章大約只保留 10 個月左右（2025-10 的政治文 404，2026-01 的文章還在），而且類別錯了直接 404，不會轉址。2014 年以前的 `udn.com/NEWS/…` 被 robots `Disallow: /NEWS/*` 擋住。robots.txt 開頭註明內容不得用於 LLM／AI 或商業用途，並封鎖多個 AI 爬蟲 UA；研究用 UA 不在封鎖名單內，但此政策風險應於研究方法中揭露。**做法**：2020-02 以後用每週 sitemap（頻道 2 每週約 1,500–6,000 個網址，其中 `story/6656/` 為政治）拿網址，再到 Wayback 取 `id_` 版本；2015–2019 用 CDX 查 `udn.com/news/story/6656/` 前綴；2012–2014 用 CDX 查 `/NEWS/` 舊制，或改用聯合知識庫。每日蒐集已保存全文（`text` 欄位），可避免日後下架造成缺漏。
- **中時**：sitemap 從 2009-10 起依時間排列，每檔約 4,000–15,000 個網址、約 3 MB。要指定 `Accept-Encoding: gzip`，因為 httpx 處理 brotli 會出錯。版別碼：即時新聞 `260407` 政治、`260402` 社會、`260403` 體育、`260404` 娛樂、`260405` 生活、`260408` 國際、`260410` 財經；報紙版：`260102` 焦點要聞、`260107` 地方、`260301` 旺報國際新聞（2012-01 實測）。2012–2013 年只有報紙版，抽到的版別裡**沒有獨立的「政治」版**，政治新聞散在焦點要聞等版，所以這兩年要用文字重新判定。sitemap 只到 2025-06-17；2025-06 以後可以用 `realtimenews/YYYYMMDDNNNNNN-260407` 探測，因為版別碼錯了也回 200，頁面會給出真正版別。
- **ETtoday**：網址裡的日期可以亂填，會 301 到正確日期；體育新聞會轉到 `sports.ettoday.net/news/<id>`。可以直接抽 ID，再用 `article:section` 篩出政治。
- **TVBS**：任何類別路徑都直接回 200，不轉址；真正的類別在 `og:url` 和 `article:section`。空號很多（約 1/3 的抽測回 404）。2026 年 ID 跳得很快（2026-01 約 3.1M，2026-11 約 4.04M）。
- **三立**：空號會 302 到 `page-error`（HTTP 500），視同不存在。2013-09 之前沒有資料。
- **民視**：robots.txt 對研究用 UA 回 403（Cloudflare），本調查未探測自家網站，只使用已蒐集資料與 Wayback。`sno` 格式至少從 2008 年就沒變（Wayback：2012 年是 `news.ftv.com.tw/NewsContent.aspx?sno=2012107F04M1&ntype=air`；2019 年起是 `ftvnews.com.tw/news/detail/2017613S12M1`）。字母意義（用本地 3 天資料推）：`P` 多為政治、`I` 國際、`F` 財經；`C`／`N`／`U`／`L`／`S` 是地方或其他類別，裡面也有政治新聞；`W`＋4 碼是網路稿，類別混雜。因此每月的 `sno` 可以完全列舉（每天約 20 個序號），但政治判定仍要看頁面上的類別。robots.txt 對研究用 UA 回 403；依 RFC 9309，robots.txt 回應 4xx 視為無限制，每日蒐集與歷史抽樣一致採此做法：2019 年起抓自家網站，之前走 Wayback 的舊站網址（`NewsContent.aspx?sno=`）。
- **東森**：`/news/view/*` 被 robots 擋（現行文章網址不在這個路徑下）。列表頁的 `?page=` 參數沒有作用（分頁走 `/list/load`，也被擋）。所以只能 ID 探測，但好處是 `/news/politics/<id>` 本身就是篩選器。實測裡非政治 ID 佔多數（9 次中 6 次轉到 `/realtime`），政治命中率估計 10–20%。2017 年以前的舊站在 Wayback 上的網址格式還沒確認。
- **公視**：舊網址 `detail.php?NEWS_ID=` 是 404，不會轉址，但 ID 和現行 `/article/<id>` 共用。類別欄位不可靠：2012-01-06、2016-03、2016-07、2019-12 的樣本沒有 `articleSection`，另有一篇 2012 年的溫泉新聞被標成「政治」。需要用關鍵詞或模型重新判定是否為政治新聞。
- **風傳媒**：月檔（例如 `article-2016-1-1.xml`）就是當月完整名單，不需要探測 ID。但類別要抓頁面才知道（只看 breadcrumb 的 `/channel/7`）。
- **鏡週刊**：舊文章自家網站還能看，但沒有任何歷史網址清單。`/category/political` 伺服器端只輸出最新約 60 篇。只能用 Wayback CDX 查 `mirrormedia.mg/story/` 前綴，或寫信向鏡週刊申請。

## 建議抽樣方法

共同原則：(1) 先拿到「當月所有候選網址」（sitemap，或在 ID／日期空間均勻抽樣）；(2) 只抓頁面、用上表的欄位判定是否為政治；(3) 每月抽到 300 篇政治文為止。用 ID 隨機抽樣的話，政治文在當月所有文章中是等機率被抽到的。

## 限制

- 各年 1 月的 ID 是內插估計，實際抽樣前每個月要先用 2–3 個 ID 校準。空號比例只來自少量樣本。
- 「可回溯到」是用很少的樣本判斷的：中央社的起點介於 2014-01 和 2014-07 之間；聯合的保留期限介於 2025-10 和 2026-01 之間；東森 2018 年以前沒找到可用 ID，不等於確定沒有。
- 各家類別體系不同（中時的焦點要聞、中央社的兩岸／國際、公視的錯標），「政治新聞」的操作型定義需要在 codebook 裡統一。
- Wayback CDX 的成功率約 50%，Wayback 路線的產量無法事先保證。
