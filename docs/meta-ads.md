# Meta 上的政治與議題廣告：媒體與政黨

日期：2026-11-27　資料：Meta 廣告檔案庫報告（台灣，截至 2026-11-23）　程式：`scripts/meta_ads_report.py`

Meta 要求在台灣投放社會議題、選舉或政治廣告的廣告主先通過身分驗證並標示出資者，這些廣告保存在廣告檔案庫。檔案庫報告列出每個粉絲專頁與出資者組合的總花費與廣告數。台灣自 2019 年 11 月起共 32,479 個組合，加總 NT$902,829,437（「≤100」以 0 計；報告頁顯示的總額為 NT$903,085,366）。媒體付費推廣自己的貼文，若 Meta 判定屬於社會議題、選舉或政治類，也會列入檔案庫，所以媒體本身也出現在報告裡。讀過各媒體粉專的廣告文字，這些廣告包含兩類：推廣自己的政治新聞，以及替企業或政府機關製作的贊助內容（例如永續專題、交通安全宣導、市府消費活動）。下表的金額是兩類的合計。

## 4. 資料取得方式

廣告檔案庫報告由報告頁的「Download report」下載，各粉專的廣告清單由公開的檔案庫網頁讀取，兩者都不登入，使用標明本研究的 User-Agent，每頁間隔 15 秒。facebook.com 的 robots.txt 不允許自動程式存取；因為 Meta 的官方 API 需要另行申請身分驗證，本研究改用開源工具（[crawl4ai](https://github.com/unclecode/crawl4ai)，解析方式參考 [facebook-ads-library-mcp](https://github.com/RamsesAguirre777/facebook-ads-library-mcp)）讀取這些公開頁面。原始頁面與貼文文字只留在本機，公開的只有上方的彙總數字。
